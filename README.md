# スライド作成進捗管理アプリ

家族心理学会 自主シンポジウムのスライド作成作業を見える化するための、個人用の進捗管理Webアプリです。

## 起動方法

```bash
npm install
npm run dev
```

表示されたURL（例: http://localhost:5173/）をブラウザで開いてください。

## ビルド

```bash
npm run build
```

`dist/` に静的ファイルが出力されます。

## 主な機能

- 5つのタスクそれぞれについて、0〜5の6段階で進捗を管理
- 「進める」「戻す」ボタン、または進捗バーの区切りを直接クリックして段階を変更
- 全体進捗率・完了タスク数・総作業時間・今日の前進ステップ数を上部に表示
- 各タスクの現在の進捗段階に作業時間（分）を記録し、段階ごと・タスクごとに集計
- 進捗5（完成）到達時にお祝いメッセージをフェード表示
- すべてのデータをブラウザのlocalStorageに保存（再読み込み・再訪問後も保持）
- 確認ダイアログ付きの全リセット機能
- スマートフォン・パソコンの両方に対応したレスポンシブデザイン
- （任意）GitHub Gistを使った端末間の進捗同期

## 技術構成

- React + TypeScript + Vite
- 外部UIライブラリ・バックエンド・データベースなし
- データ永続化はブラウザのlocalStorage（＋任意でGitHub Gist）

## どこからでもアクセスする（GitHub Pages）

このリポジトリは公開（Public）リポジトリです。`main`ブランチにpushすると、
`.github/workflows/deploy.yml`のGitHub Actionsが自動でビルドし、
`https://<GitHubユーザー名>.github.io/slide-progress-app/` に公開されます。

初回のみ、リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください。

公開リポジトリのため、URLを知っていれば誰でも閲覧できます。中身はタスク名と進捗数値・作業時間のみです。

## 端末間で進捗を同期する（任意）

画面下部の「他の端末と同期」から、GitHub Gistを使って進捗データをPCとスマホなど複数端末で共有できます。

1. [GitHubのトークン発行ページ](https://github.com/settings/tokens/new?scopes=gist)を開き、
   スコープは **gist のみ** にチェックしてトークンを発行する
2. 同期したい各端末のアプリで「他の端末と同期」を開き、発行したトークンを貼り付けて「接続」
3. 2台目以降の端末では、**同じトークン**を貼り付けて接続すると、既存のGistを見つけて同じデータに同期する

### 仕組みと注意点

- トークンはその端末のブラウザのlocalStorageにのみ保存され、外部には送信されません（GitHub API通信のみに使用）
- 進捗データは非公開（private）のGitHub Gistに保存されます
- データが変わってから1.5秒後に自動でGistへ保存し、起動時・「今すぐ同期」実行時にGistの内容と比較します
- 競合解決は「更新日時が新しい方を採用する」単純な方式（last-write-wins）です。2台でほぼ同時に編集すると、後から同期した方の内容で上書きされることがあります
- 「同期を解除」はその端末のトークン情報を消すだけで、Gist自体は削除されません
